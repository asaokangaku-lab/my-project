# デスクトップ整理テンプレート

デスクトップの `claude/` フォルダを整理するためのフォルダ構造テンプレートです。

👉 **全体像は [FOLDER_STRUCTURE.md](./FOLDER_STRUCTURE.md) を参照**（ツリー図あり・スクショ用）

## 使い方

1. `claude/` フォルダをそのままデスクトップにコピー／同期する
2. 既存ファイルをカテゴリごとに振り分ける
3. 未分類は `99_inbox` に一旦入れる（週1で仕分け）
4. ショートカット（`.lnk`）は `80_よく使う` に集約

## 設計ポリシー（ADHDフレンドリー）

- 階層は**最大4まで**
- フォルダ名は**`00_` `10_` `20_`** の数字プレフィックスでソート固定
- 10刻みなので**後から割り込み**OK（`05_`など）
- 打合せは `MMDD_内容`、年度は `YYYY_内容`
